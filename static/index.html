設定

AI 功能透過這台電腦上的 Claude Code CLI 執行，用量會計入你的 Claude 方案。 Opus 5.5 最強但最慢；effort 越高想得越久。只求速度時，翻譯用 Sonnet 5.5＋「不思考」最快。

書庫位置（OneDrive／Google Drive 雲端同步）

用 DOI／PMID／PMCID 匯入

每行一筆：DOI（10.xxxx/…）、PMID、PMCID（PMC…）或論文網址。會依序試出版社的開放取用 PDF、PMC 開放取用資料集； 需要訂閱、或網站擋程式下載時，請在瀏覽器開啟後用 Chrome 擴充功能「用論文伴讀開啟」或直接拖曳 PDF。PMC 來源下載較慢（約 30–60 秒）。

書庫位置與雲端同步

把書庫放進 OneDrive 或 Google Drive 電腦版正在同步的資料夾，就會由它們負責上傳、同步到你的其他電腦。論文伴讀本身不連線雲端，也不需要登入帳號。
